УстановкаInstall

flatpak install --user https://cheviiot.github.io/Alcove/alcove.flatpakref

5 МБ загрузки, 13 МБ на диске. Нужен Flatpak и среда org.gnome.Platform 50 — если её нет, Flatpak поставит её с Flathub сам.

A 5 MB download, 13 MB installed. You need Flatpak and the org.gnome.Platform 50 runtime; if it is missing, Flatpak pulls it from Flathub for you.

Репозиторий и все сборки подписаны ключом проекта. Есть и готовые пакеты — на странице выпусков.

The repository and every build are signed with the project key. Ready-made bundles are on the releases page.

Движок ChromiumThe Chromium engine

flatpak install --user https://cheviiot.github.io/Alcove/alcove-chromium-native.flatpakref

По умолчанию работает WebKitGTK, он уже внутри. Chromium — для сайтов, которым WebKitGTK не хватает: ставится отдельно и только по вашему решению.

WebKitGTK is the default and is already inside. Chromium is for sites WebKitGTK cannot serve: it installs separately, only if you choose it.

150 МБ загрузки, 364 МБ на диске, только x86_64. После установки закройте и откройте Alcove заново.

A 150 MB download, 364 MB installed, x86_64 only. Close and reopen Alcove afterwards.
